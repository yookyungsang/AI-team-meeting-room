# Team Meeting Room icon

![회의 테이블과 말풍선 아이콘](team-room-icon.png)

The same square PNG is referenced by `logo` and `composerIcon` in both plugin
manifests. It represents a meeting table, chairs and two speech bubbles, with
no text. Its colors and solid tile provide contrast in light and dark contexts;
no separate theme variant or background service is required.

Delivered file: 1254 × 1254 pixels, RGB PNG, 1,226,836 bytes. The full PNG was
decoded and verified locally. Isolated CLI installation preserved the exact
image bytes and both manifest references; native-app display remains unverified.

Created once with the built-in `image_gen` tool for this plugin at the user's
request. No reference images or user-conversation screenshots were used.
The icon is distributed with the plugin under its [MIT license](../LICENSE).
Generating this asset is separate from displaying it: displaying the packaged
icon adds no model call to the meeting workflow.

## Generation prompt

Use case: logo-brand. Create ONE finished square app icon for a desktop plugin
named Team Meeting Room. Primary request: combine a meeting table and speech
bubbles into one clean, memorable symbol for team collaboration. A simple
rounded meeting table with a few minimal chair shapes in the lower part; two
clean overlapping speech bubbles above it. Flat geometric vector-like
illustration, bold smooth silhouettes, thick shapes, generous negative space,
carefully centered composition and optical balance. Legible as a tiny 24–48 px
app icon. A restrained high-contrast treatment suitable for both light and dark
desktop interfaces, on a solid dark rounded-square app tile. Keep the symbol
well inside the tile with safe padding. The whole image is square, a single
complete icon only. No words, no letters, no numbers, no watermark, no brand
logos, no tiny details, no photorealism, no scene outside the icon, no multiple
variants or presentation board. Export as a crisp square image, ideally
1024x1024.

Generation requested an opaque background. The delivered source image is used
directly without visual editing or an additional generation.
