        설명을 보거나 취소할 때는 AI를 호출하지 않습니다. 요청문 준비까지는 AI를 호출하지 않습니다. 채팅 입력창에서 요청문을 확인하고 직접 전송하면 생성·초기화 사용량이 발생합니다. 기존 설정은 같은 요청문으로 이어갑니다.

        입력창에서 내용을 확인하고 직접 전송하세요. 입력창 넣기가 지원되지 않으면 요청문을 복사해 같은 프로젝트 채팅에 붙여 넣어 보내세요. 직접 전송 전에는 대화창을 만들지 않습니다.

        연결 점검 결과

          프로젝트·총괄·호스트 지원을 읽기 전용으로 확인합니다. 채팅 생성이나 AI 호출은 하지 않습니다. 실제 생성 권한은 팀 설정 때 확인합니다.

          회의 기록 백업·내보내기

          회의 원문·작업 상세·이미지·음원을 ZIP으로 보관합니다. 압축을 푼 뒤 index.html을 열면 오프라인으로 볼 수 있습니다. 원본 기록은 유지하며 자동 복원은 포함되지 않습니다.

          회의 내용과 연결 정보가 포함된 개인 백업입니다. 공개 저장소에 올리지 마세요.

          백업 불러오기

          이 플러그인에서 만든 ZIP을 원래 프로젝트에서 확인하고, 없어진 회의실만 복구합니다. 기존 기록을 덮어쓰거나 진행 중인 작업을 다시 실행하지 않습니다.

          파일 선택은 16 MiB까지입니다. 더 큰 백업은 아래 파일 경로로 최대 128 MiB까지 확인할 수 있습니다. 파일은 로컬 플러그인에만 전달됩니다.

                이 회의실을 삭제할까요?
                회의실 목록에서 제거하고 기록은 복구할 수 있게 보관합니다. 실제 Codex 대화창·프로젝트 파일은 유지합니다. 진행 중인 작업·질문·점유·검증·팀 설정을 먼저 정리해야 합니다.
                

                삭제된 회의실
                보관된 회의실을 원래 담당자·기록 그대로 복구합니다. 실제 채팅을 생성하거나 AI를 호출하지 않습니다.
                  

                  사용 방법과 사용량 안내

                  누구에게 전달되나요?
                  선택한 프로젝트의 총괄에게 전달됩니다. 다른 채팅에서 회의실을 열었다면 해당 총괄 채팅으로 한 번 전달될 수 있습니다.
                  

                  작업 중에도 추가로 보낼 수 있어요
                  추가 내용은 진행 중인 요청에 연결됩니다. 총괄이 중간 판단과 완료 전에 확인합니다. 앱의 메시지 처리 방식에 따라 현재 작업에 반영되거나 다음 순서로 대기할 수 있습니다.
                  

                  전송 상태를 확인해 주세요
                  • 전송 확인 대기: 내용은 저장됐고, 채팅으로 전달됐는지 확인 중입니다.
                  • 호스트 전달 확인: 채팅에서 전송을 접수했습니다. 실제 작업 완료 여부는 회의 기록에서 확인해 주세요.
                  • 확인 필요 · 전송 거절: 해당 요청 ID로 총괄 채팅에서 처리 여부를 확인해 주세요. 자동으로 다시 보내지 않습니다.
                  

                  사용량은 언제 발생하나요?
                  대기 중에는 AI를 호출하지 않습니다. 요청을 보내 총괄과 담당자가 실제로 작업할 때 정상적인 사용량이 발생합니다.
                  

                  작업 중 이미지도 볼 수 있어요
                  담당자가 중간 시안이나 스크린샷을 진행 보고에 첨부하면 대화 안에 표시됩니다. 이미지를 누르면 크게 볼 수 있습니다. 다른 채팅의 이미지를 자동 수집하지는 않습니다. 이미지 표시·확대는 AI를 호출하지 않으며 생성·분석 작업에는 정상 사용량이 발생합니다.
                  

                  어려운 설명은 작업 상세에서 볼 수 있어요
                  새 보고는 완성한 것, 아직 확인할 것, 다음 할 일을 쉬운 말로 먼저 안내합니다. 담당자가 함께 남긴 파일명·검사 기록은 ‘작업 상세 보기’를 눌러 확인할 수 있습니다. 펼치기는 AI를 호출하지 않습니다. 기존 글을 자동으로 번역하거나 다시 쓰지는 않습니다.
                  

                  일시정지는 새 요청만 막아요
                  이미 진행 중인 작업을 취소하지는 않습니다. 확인이 필요한 전송이 있어도 다른 추가 내용은 계속 보낼 수 있습니다.
