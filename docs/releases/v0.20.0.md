# v0.20.0 · 공개 베타 · 작업 현황과 복구 안내

회의실 위쪽에서 진행 요청, 결과 대기, 배정 대기, 미답변 질문, 보관된 실패 기록을
확인할 수 있습니다. 이전 대화 페이지를 보고 있어도 전체 저장 기록을 기준으로
표시하며, 연결이 끊기면 마지막으로 받은 상태라고 안내합니다. 실제 채팅의 실행·중단을
자동 판정하거나 진행률을 추정하지 않습니다.

**작업·복구 안내**는 기존 체크포인트, 남은 작업, 파일·Editor 점유, 관련 검증과
미답변 질문을 모아 보여줍니다. **총괄에게 확인할 요청문 준비 → 요청문 복사**로
검토용 문장을 준비하고 같은 프로젝트의 총괄 채팅에서 직접 전송할 수 있습니다.
작성 중인 입력과 원문은 유지합니다. 안내를 열거나 복사해도 작업이 재시작되거나
메시지가 전송되지 않으며, 기존 승인·실행 키·복구 및 소유권 절차를 유지합니다.

기존 로컬 화면 갱신을 사용하고 복구 상세는 사용자가 열 때만 읽습니다. 별도 AI,
native 채팅 반복 조회, 자동 재전송, 새로운 상주 감시는 추가하지 않습니다.
실제 확인 요청을 전송한 후의 총괄 작업에는 일반 사용량이 발생합니다.
메뉴와 안내 문구는 한국어·영어·일본어·중국어 간체·번체를 지원합니다.

[자세한 사용법](../../host-plugin/skills/team-room/references/work-status.md).
자동 검사 285개와 격리 브라우저 검사 32개를 통과했습니다. 큰 화면·작은 화면에서
상단 현황, 체크포인트 안내, 원래 입력 유지, 요청문 준비만 수행하는 동작을 확인했습니다.
합성 1만 건에서 최근 페이지·변화 없는 응답의 크기 제한과 로컬 처리 성능도 확인했습니다.
격리 자동·브라우저 검사와 실제 Codex 표시 확인은 구분합니다. 업데이트 후
실제 앱 재시작과 화면 전환 확인은 별도이며 공개 베타를 유지합니다.

## 설치·업데이트 / Install and update

기존 소스 폴더에서 다음 명령을 실행한 뒤 앱을 완전히 종료하고 다시 실행하세요.
설치 ID와 MCP 키, 소스 폴더 밖의 기존 회의 기록은 유지합니다.

Run these commands in the existing source checkout, then fully quit and restart
the app. The plugin/server identity and externally stored room records are preserved.

```sh
git pull
codex plugin marketplace add .
codex plugin add team-room@team-room-local
```

## English

A compact overview shows saved work counts above the conversation. The read-only
work/recovery guide presents checkpoints, next steps, ownership and related
validation obstacles. It prepares a copyable director review request without
changing the existing draft or automatically sending, approving or restarting
anything. Actual native stop verification and existing director-only recovery
gates still apply. The existing local UI refresh is reused, with no new AI or
native polling. All five UI languages are supported. This remains a public beta;
isolated browser tests do not certify native Codex display transitions.
