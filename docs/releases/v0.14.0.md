# v0.14.0 · 연결 점검·ZIP 백업·영문 메뉴·실제 UI 영상

- **메뉴 → 연결 점검**에서 프로젝트 인식·총괄·담당자 목록·호스트 전송과 초안 지원을 확인합니다. 실제 생성 권한은 미확인으로 구분하고 해결 방법을 보여 줍니다.
- **메뉴 → ZIP으로 백업**에서 현재 회의실의 원문·작업 상세·이미지·음원을 보관합니다. 압축을 풀고 `index.html`을 열면 오프라인으로 볼 수 있습니다. 원본 JSON·Markdown·파일별 SHA-256도 포함합니다.
- **메뉴 → 화면 언어 / Language**에서 한국어와 English를 선택합니다. 자동은 한국어 브라우저에 한국어, 그 외에 영어를 사용합니다. 기존 발언과 사용자 원문·첨부 설명·모델은 바꾸지 않습니다.
- 실제 위젯과 로컬 도구를 예시 데이터로 실행한 약 1분 [사용 영상](../DEMO.md)을 추가했습니다. 격리 브라우저 녹화이며 실제 Codex 승인·새 채팅 생성 또는 실시간 에이전트 영상은 아닙니다.

점검·백업·언어 전환은 별도 AI를 호출하지 않습니다. 실제 업무와 팀 설정에는 일반 사용량이 있습니다. 기록과 연결은 그대로 유지하고 자동 복구·자동 가져오기·정기 백업은 추가하지 않습니다.

ZIP은 최대 128 MiB이며 누락·손상 파일은 부분 성공으로 숨기지 않습니다. 호스트 다운로드는 지원할 때 16 MiB까지 가능하고 더 큰 파일은 저장된 로컬 경로에서 복사합니다. 백업에는 개인 대화와 연결 정보가 있으므로 공개 저장소에 올리지 마세요.

## 설치·업데이트

저장소를 내려받은 폴더에서 실행하고 진행 중인 작업을 마친 뒤 Codex를 재시작합니다.

```sh
git pull --ff-only
codex plugin add jyfood-room@jyfood-local
```

## Validation / English

Includes explicit read-only connection checks, scoped ZIP backups with offline HTML/Markdown/media, packaged English/Korean labels, and a recorded one-minute actual-widget walkthrough using sample data. No translator AI, background model work or native chat creation is added. Existing identities, original posts and model choices are preserved.

Regression tests cover private metadata transport, cross-project isolation, exact export retries, source preservation, missing/corrupt attachments, ZIP integrity, path containment, language switching and late callbacks. Browser checks include 420px/1280px layouts and real export downloads; Python's independent ZIP reader also verifies the archives. Native Codex host approval/display transitions remain a separate integration check. See [demo scope and reproduction](../DEMO.md).
