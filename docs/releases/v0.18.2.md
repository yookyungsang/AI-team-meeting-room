# v0.18.2 · 공개 베타 · 일회용 탭 열기와 메뉴 간격

v0.18.0 이후의 변경을 함께 제공합니다. 새 열기 요청은 로컬의 일회용 표시 기록을
저장한 뒤 탭 전환을 한 번 요청합니다. 과거 카드가 다시 보이는 것만으로 사용한
요청을 반복하지 않습니다. 이전 표시 기록이 남아 있으면 상단 탭을 먼저 확인하고,
실제로 탭이 없을 때만 **기존 탭 없음 · 다시 열기**로 복구합니다. 채팅·작업은
그동안에도 계속 사용할 수 있습니다. [동작과 한계](../../host-plugin/skills/team-room/references/room-opening.md).

이 기능은 기존 탭을 조회·선택·통합하는 기능이 아닙니다. 앱 강제 종료/복원,
수동 펼치기·호스트 메뉴·구버전 탭까지 포함한 완전한 중복 방지는 보장하지 않습니다.

회의실 메뉴의 ‘화면 언어 / Language’ 설명과 언어 선택 목록 사이에 12px 간격을
두고 세로 중앙을 맞춥니다. 화면이 좁으면 8px 간격으로 다음 줄에 배치합니다.
화면 표시만 조정하며 언어 선택·회의 기록·AI 호출 동작은 유지합니다.

자동 검사 273개와 격리 브라우저 검사 26개를 통과했습니다. 실제 앱에서 언어
간격·전환·연결 점검, 전송하지 않은 초안의 비차단 경고, 공유 ZIP 선택값·무결성·
원문 보존을 확인했습니다. 양성 가림과 native 탭 재시작 검증의 범위는
[실제 앱 검증 기록](../host-validation.md)에 구분해 적었습니다. 별도 AI·heartbeat·
정기 표시 조회·자동 재전송은 추가하지 않습니다.

기존 설치는 소스 업데이트 후 `codex plugin marketplace add .`와
`codex plugin add team-room@team-room-local`로 갱신하고 앱을 완전히 재실행하세요.
업데이트 전에 구버전 회의실 탭은 직접 정리해 주세요.

## English

Fresh openings durably consume a one-use display request; replayed cards do not
repeat it. Existing/uncertain occupancy needs a human no-old-tab check before
one-shot recovery. This is a conservative guard, not native tab discovery or
universal deduplication. No extra AI, heartbeat or automatic resend is added.

The menu language label and picker now have a 12px horizontal gap and centered
alignment. Narrow layouts wrap with an 8px row gap. This only changes spacing.
273 automated and 26 isolated browser cases passed. Native checks and remaining
limitations are recorded in the linked validation report. Reinstall through the
existing selector and fully restart the app; manually clean up obsolete tabs.
