# v0.17.0 · 공개 베타 · 회의실 설치 이름과 아이콘

> **공개 베타 / Public beta.** 실제 앱의 처음 팀 생성, 작업·QA·복구 전체 흐름과
> 재시작·중복 탭 검증은 계속 진행 중입니다. 이 버전은 설치 이름 변경이며 해당
> 호스트 동작이 검증 완료됐다는 뜻은 아닙니다. [검증 범위](../../host-plugin/skills/team-room/references/host-validation.md).

사용자가 요청한 설치 이름 변경을 적용합니다. 새 플러그인 이름은 `team-room`,
마켓플레이스는 `team-room-local`, 설치 선택자는 `team-room@team-room-local`입니다.
Codex에 표시되는 이름은 **팀 회의실**, MCP 서버 키는 **team-room**입니다.

회의 테이블·의자와 말풍선을 조합한 [전용 아이콘](../../host-plugin/assets/README.md)을
추가합니다. 같은 이미지를 목록 로고와 입력창 아이콘에 연결했으며, 기존·호환
manifest 모두 같은 파일을 사용합니다. 이미지 표시용 모델 호출은 추가하지 않습니다.
실제 앱에서의 표시와 캐시 갱신은 설치 후 별도 확인 대상입니다.

## 처음 설치

Node.js 22 이상, Git, 로컬 플러그인과 MCP Apps를 지원하는 Codex 및 `codex`
명령이 필요합니다. 설치용 폴더에서 한 줄씩 실행하세요.

```sh
git clone https://github.com/yookyungsang/AI-team-meeting-room.git
cd AI-team-meeting-room
codex plugin marketplace add .
codex plugin add team-room@team-room-local
```

기존 이름으로 설치했다면 바로 중복 설치하지 말고 먼저
[설치 이름 이전 안내](../../host-plugin/MIGRATION.md)를 따르세요. 진행 중인 작업을
마치고 이전 설치를 제거한 뒤 새 이름으로 설치하고 Codex를 다시 실행합니다.

## 보존 범위와 검사

- 기존 회의실 데이터 위치·프로젝트와 담당자 연결·대화 기록은 바꾸지 않습니다.
  `TEAM_ROOM_HOME`을 직접 설정했다면 새 설치에서도 같은 값을 유지합니다.
- 기존 대화와 회의실을 새로 생성하거나 자동 변환하지 않습니다. 설치 이름 변경에
  필요한 모델 호출·주기적 작업·자동 재전송을 추가하지 않습니다.
- 두 manifest, 마켓플레이스, 현재 설치 설명서 5개 언어와 패키지 검사를 새 이름에
  맞춥니다. 이전 릴리스의 설치 이름은 당시 기록으로 보존합니다.
- 패키지 검사(문서 링크 327개)와 자동 검사 237개가 통과했습니다. 별도 가상
  환경에서 Codex CLI로 이전 설치 제거·새 이름 설치·MCP 초기화·도구 목록과
  기존 프로젝트 읽기를 확인했고, 가상 회의실 파일은 바이트 단위로 동일했습니다.
  Windows 샌드박스의 junction·임시 파일 rename 권한 제한으로 실패한 검사는
  같은 가상 검사만 제한 밖에서 실행해 통과를 확인했습니다.
- 위 검사는 실제 Codex 앱에서 기존 설치를 제거하고 재시작하는 전체 전환을
  인증하지 않습니다. 실제 사용자 설치와 데이터는 이 검증에서 바꾸지 않았습니다.

## English

The user-requested install identity is now **`team-room@team-room-local`**:
plugin `team-room`, marketplace `team-room-local`. The display name and MCP
server key stay unchanged. Use the first-install commands above, or follow the
[existing-install migration](../../host-plugin/MIGRATION.md) before installing
under the new name. Avoid running both identities at once.

Meeting data stays outside the source package at its existing default or
`TEAM_ROOM_HOME` location. Project/chat routes, history, attachments, ownership,
validation and usage records are not rewritten. No chats, model calls, polling
or automatic migrations are added. Current Korean, English, Japanese,
Simplified Chinese and Traditional Chinese guides use the new selector;
historical release notes retain their original IDs. All 237 regression tests
and the package check (327 local document links) passed. An isolated Codex CLI
migration removed the old cache, installed the new selector, initialized MCP,
listed tools and read the existing synthetic project with byte-identical room
files. Windows permission-restricted fixture tests passed outside the sandbox.
The isolated verification changed no real installation or runtime data. Native-app removal, restart
and saved-tab migration remain separate validation work.

A new meeting-table and speech-bubble icon is packaged for both `logo` and
`composerIcon`, with identical paths in the portable and compatibility
manifests. It adds no runtime model calls. Actual native-app icon rendering and
cache refresh still require an installation/restart check. A complete PNG decode
and isolated installation verified the delivered image, both manifest references
and byte-identical copying into the plugin cache.
