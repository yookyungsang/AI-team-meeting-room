# v0.13.2 · First-project setup fixes / 첫 프로젝트 팀 설정 수정

## 한국어

- 연결 전에도 현재 프로젝트 이름과 **팀 연결 전** 상태를 표시합니다.
- **기본 팀 만들기**를 다시 누르면 열린 설명이 닫힙니다. 늦게 도착한 응답은 다시 열지 않습니다.
- **설명 확인 · 요청문 준비**는 요청문을 편집 가능한 채팅 초안으로 준비합니다. 내용을 확인하고 직접 전송하세요. 지원되지 않으면 보이는 요청문을 복사해 같은 프로젝트 채팅에 보내면 됩니다.
- 이전 생성 요청이 막힌 경우에도 원래 계획·역할별 모델·생성 시도 이력을 보존한 이어가기 요청문을 제공합니다. 중복 팀을 만들거나 승인 검토를 우회하지 않습니다.

메뉴 기록만으로 새 대화창 생성을 직접 승인했다고 판단하지 않습니다. 요청문 준비까지는 AI를 호출하지 않으며, 직접 전송한 뒤 실제 생성·역할 초기화에는 일반 사용량이 발생합니다.

## English

- Show the verified project name before its room is connected.
- Make the Basic team trigger close its open explanation, including pending previews.
- Prepare an editable native-chat draft with `send:false`; the human reviews and sends it. Unsupported/rejected draft insertion provides copyable text, with no automatic submission fallback.
- Reopen blocked setups with their original continuation, models and attempt history. A saved menu receipt is not authenticated human approval; host review is preserved.

## Install / update · 설치와 업데이트

Install Node.js 22 or later, Git and a Codex version supporting local plugins/MCP Apps.
새 설치는 다음 명령을 사용합니다.

```sh
git clone --branch v0.13.2 https://github.com/yookyungsang/AI-team-meeting-room.git
cd AI-team-meeting-room
codex plugin marketplace add .
codex plugin add jyfood-room@jyfood-local
```

Existing installations: finish active work and preserve local edits before checkout.
기존 설치는 소스 폴더에서 실행하고, 작업을 마친 뒤 Codex를 완전히 재시작합니다.

```sh
git fetch --tags origin
git checkout v0.13.2
codex plugin add jyfood-room@jyfood-local
```
