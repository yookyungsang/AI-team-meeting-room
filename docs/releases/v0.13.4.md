# v0.13.4 · 팀 생성 진행 화면과 이어하기

팀 구성 중 회의실 본문에 새 담당자 준비 수와 역할별 상태를 표시합니다.
원래 대화를 쓰는 총괄은 별도 행에 표시하며 새 담당자 5명 수에 포함하지 않습니다.

- 요청문 직접 전송 대기, 생성 결과 확인, 오류, 회의실 연결 완료를 구분합니다.
- 초기 연결 완료 전에는 회의실 작업 입력만 잠시 읽기 전용으로 두고 초안을 유지합니다.
- Codex 원래 채팅에서는 중단 요청·오류 상담을 계속할 수 있습니다.
- 창을 닫거나 Codex를 다시 열어도 저장된 원래 계획과 이미 만든 채팅을 유지합니다.
- **중단·오류 후 이어하기**는 원래 요청문을 입력창에 준비하거나 복사하게 합니다.
  내용을 확인하고 원래 총괄 채팅에서 직접 전송해야 이어갑니다.
- 오류는 **문제 자세히 보기**에서 확인합니다. 실제 생성 결과가 불확실하면
  다시 만들지 않고 원래 시도와 실제 채팅부터 확인합니다.
- 기존 회의실을 확장하는 설정은 진행 중인 기존 업무 입력을 막지 않습니다.

진행 화면은 기존 UI 갱신에서 저장된 로컬 기록만 읽으며 별도 AI 감시·native
채팅 반복 조회·자동 재전송을 추가하지 않습니다. 화면 닫힘이나 시간 경과만으로
실제 작업 중단·미생성을 단정하지 않습니다. 실제 생성·재개와 역할 초기화에는
일반 사용량이 있습니다. 연결 완료 뒤 회의실 입력은 자동으로 활성화됩니다.

## 설치·업데이트

저장소를 내려받은 폴더에서 실행합니다.

```sh
git pull --ff-only
codex plugin add jyfood-room@jyfood-local
```

진행 중인 작업을 마친 뒤 Codex를 완전히 종료하고 다시 실행하세요.
[처음 설정 안내](../../host-plugin/SETUP.ko.md)를 참고하세요.

## 검증

격리 데이터로 자동 검사 200개를 통과했습니다. 독립 Chromium의 420px·1280px
화면에서 진행·오류·이어하기 초안·완료 후 입력 활성화와 기존 화면 회귀를
확인했습니다. 실제 사용자의 대화창을 만들거나 중단·재개하지 않았으며,
실제 Codex의 승인·생성·표시 전환은 별도 실사용 확인 항목입니다.

## English

The main room view shows saved team setup progress, role states and errors.
Initial setup keeps only the meeting composer read-only until connection,
preserving its draft and access to the original Codex chat. Existing-room
extensions keep ongoing work usable.

Closing/reopening preserves the original journal and ready workers. Explicit
continuation prepares an editable draft or copyable request; the human must
review and send it in the original director chat. Actual native outcomes are
reconciled before an authorized retry. No background AI, native polling,
automatic resend or replacement team is added. See the
[English setup guide](../../host-plugin/SETUP.en.md).
