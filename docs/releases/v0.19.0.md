# v0.19.0 · 공개 베타 · 설치 요구 버전과 긴 기록 개선

Node.js 최소 요구 버전을 **22.13.0**으로 명확히 했습니다. 필요한 SQLite API가
없는 실행 환경에서는 서버 시작 전에 업데이트 방법을 안내합니다. GitHub 자동
검사는 최소 버전과 Node 24를 Windows·Linux에서 각각 실행합니다.

긴 기록은 최대 100개·약 192KiB의 메시지 페이지로 읽습니다. 단일 큰 원문은 자르지
않습니다. **이전 대화 보기 / 최근 대화 보기**로 이동하며, 입력 초안과 진행 중인
작업의 추가 지시 연결은 유지합니다. 메뉴에는 활성 요청·최근 완료/실패 20개와
현재 페이지에 연결된 이전 요청을 표시합니다. 원문·담당자의 요청 조회·전체 백업은
그대로 유지합니다. 변경 없는 화면 갱신에서는 메시지를 다시 보내거나 다시 그리지
않습니다. 별도 AI·자동 재전송·대기 호출은 추가하지 않습니다.

100·1,000·10,000건 가상 기록의 로컬 MCP 응답을 비교했습니다. 1만 건에서 전체
응답 약 29MB 대신 첫 페이지 약 292KB, 변경 없는 갱신 약 1.7KB였습니다. 이 수치는
텍스트와 구조화 결과를 포함한 전송량이며 실제 앱 지연이나 토큰 절약률이 아닙니다.
`node scripts/check-history.mjs`로 재현할 수 있습니다.

자동 검사 277개와 격리 브라우저 검사 28개를 통과했습니다. 사용자가 승인한 실제
개발자·QA 채팅으로 체크포인트 중단 → 같은 담당자 재개 → 독립 QA 확인을 수행했고
실제 회의실에 각자의 보고가 표시됨을 확인했습니다. 예기치 않은 OS/앱 강제 종료,
처음부터 기본 팀 전체 만들기, 설치 후 긴 기록의 실제 Codex 표시와 입력 전송까지
통과한 것으로 계산하지 않습니다. [검증 범위와 남은 항목](../host-validation.md).

백업 복구 검사에서 앱 도구가 만든 담당자 대화가 목록에서 빠지는 문제도 수정했습니다.
원래 프로젝트 소속이 확인된 사용자 소유 대화만 포함하며 내부 에이전트는 제외합니다.
실제 검증용 백업의 격리 복원·커밋 중단 후 같은 요청 재개도 확인했습니다.

기존 소스를 업데이트한 뒤 아래 명령으로 설치를 갱신하고 Codex를 완전히 다시
실행하세요. 기존 회의실 탭은 먼저 직접 정리해 주세요.

```sh
git pull
codex plugin marketplace add .
codex plugin add team-room@team-room-local
```

## English

Requires Node.js **22.13.0+** with `DatabaseSync.function`; unsupported runtimes
receive a startup explanation. CI covers the exact minimum and Node 24 on Windows
and Linux. Long histories use bounded pages, preserve drafts and active follow-ups,
and reuse unchanged revisions without another AI call. Originals, peer reads and
full backups remain complete. The request menu also retains requests linked to the
current message page. Reproduce the synthetic load comparison with
`node scripts/check-history.mjs`; transfer bytes do not establish token savings.

277 automated tests and 28 isolated browser cases passed. Two explicitly approved
native worker chats demonstrated controlled checkpoint stop, same-worker recovery,
and independent QA, with their own posts visible in the real room. This is not a
claim of unexpected crash recovery, full basic-team onboarding, native input-send,
or updated native long-history display coverage. See the linked validation limits.
Native-created sidebar chats now appear only with verified original project membership; internal agents remain excluded. Actual test-room backups passed isolated restore and controlled commit-interruption recovery. This release remains a public beta. Reinstall through the existing selector and
fully restart Codex; settings and runtime data are kept outside the source package.
