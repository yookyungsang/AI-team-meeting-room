# v0.13.3 · 처음 대화창을 총괄로 사용

새 프로젝트에서 **메뉴 → 기본 팀 만들기 → 설명 확인 · 요청문 준비**를
누르고 요청문을 직접 전송하면, 처음 연 대화창을 총괄로 사용합니다.

- 현재 대화창 이름을 `프로젝트명 · 총괄 디렉터`로 바꿉니다.
- 대화 내용과 현재 모델·추론 설정을 유지합니다.
- 기획자·디자이너·프로그래머 2명·QA의 새 대화창 5개만 만듭니다.
- 연결 후 다른 총괄방으로 이동하지 않고 같은 대화에서 작업을 지시합니다.
- 기존 회의실과 이전 버전에서 준비한 계획은 원래 총괄·모델·예약을 유지합니다.

총괄의 이름 변경도 한 번만 예약하고 실제 native 결과를 확인합니다.
프로젝트 소속이 달라지거나 이름 변경이 불확실하면 중단 기록을 보존하며
대체 총괄을 만들지 않습니다. 서버는 AI나 채팅 도구를 실행하지 않고,
메뉴 초안은 자동 전송하지 않습니다. 담당자 초기 설정에는 일반 사용량이
있으며 반복 AI 확인은 추가하지 않습니다.

## 설치·업데이트

저장소를 내려받은 폴더에서 다음을 실행합니다.

```sh
git pull --ff-only
codex plugin add jyfood-room@jyfood-local
```

진행 중인 작업을 마친 뒤 Codex를 완전히 종료하고 다시 실행하세요.
[처음 설정 안내](../../host-plugin/SETUP.ko.md)를 참고하세요.

## 검증 범위

합성 프로젝트로 원래 총괄 ID 고정, 작업자와 중복 연결 방지, 이름 변경 예약의
중단·복구, 소속 재확인과 이전 계획 보존을 검사합니다. 실제 사용자 대화창을
생성하거나 이름을 바꾸는 실사용 검증은 하지 않습니다. 브라우저 검사는
독립 Chromium 환경이며 실제 Codex 표시 전환·직접 승인은 별도 검증 항목입니다.

## English

New basic teams reuse the original setup chat as director, rename it to
`Project name · 총괄 디렉터`, and retain its history and current model/effort.
Only the planner, designer, two programmers and QA get new chats. Continue
working in the same original chat after connection. Existing rooms and legacy
plans keep their original identities, choices and reservations.

The guarded director action is `set_thread_title`, never `create_thread`.
Native membership and actual title receipts must be verified before connection.
No background AI, automatic submission or replacement director is added.
Update with the commands above and restart Codex. See the
[English setup guide](../../host-plugin/SETUP.en.md).
