# v0.17.2 · 공개 베타 · 이전 대화의 자동 탭 열기 방지

대화를 위로 스크롤해 예전 회의실 카드가 다시 표시될 때, 새 별도 탭으로
자동 확장되는 경로를 줄입니다. 리소스의 초기 표시 방식을 `inline`으로
명시하며, 회의실 카드가 대화 안에 표시되도록 합니다.

- 크게 보려면 카드에 표시되는 앱의 기존 펼치기 버튼을 사용합니다.
  메뉴에서 직접 회의실을 여는 thread 진입점과 fullscreen 지원은 유지합니다.
- 별도의 탭 관리 버튼·AI 호출·상태 조회·자동 재전송을 추가하지 않습니다.
  회의 기록·첨부·담당자 연결·작업 배정·QA·사용량 집계는 바꾸지 않습니다.
- 반복 표시, 숨김과 복원, 새 프레임 시작에서 자동 탭 요청이나 작업 전달이
  발생하지 않는지 검사합니다. 격리된 실제 브라우저에서 카드 재시작,
  원문 유지, 수동 fullscreen 전환과 한 번의 명시 전송을 확인합니다.

표시 우선을 생략하면 이 앱은 fullscreen을 기본으로 선택할 수 있으므로
`inline`을 명시해야 합니다. 동작 근거는 [공식 표시 방식 규격](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md#display-modes)과
설치된 앱 코드의 읽기 전용 점검입니다. 자세한 [검증 범위](../../host-plugin/skills/team-room/references/host-validation.md)를
함께 확인해 주세요.

## 업데이트와 남은 확인

패키지 검사(문서 링크 335개), 회귀 검사 247개와 격리된 브라우저 시나리오
22개가 통과했습니다. 두 화면 크기에서 카드 시작/재시작 4회씩 자동 확장과
작업 전달이 0회였고, 명시 전송은 1회였습니다. 별도 설치 환경의 업데이트,
설치 파일 63개의 원본 일치와 MCP 시작·새 표시 설정도 확인했습니다.
샌드박스가 차단한 테스트용 로컬 페이지와 임시 파일/junction 검사는 같은
가상 데이터만 제한 밖에서 실행했습니다.

기존 소스 폴더에서 `git pull` 후 아래 명령을 실행하세요.

```sh
codex plugin add team-room@team-room-local
```

진행 중인 작업이 끝나면 이미 열린 중복 탭을 정리하고 Codex를 완전히
종료했다가 다시 실행해 새 설치본과 리소스 설정을 로드합니다. 이미 열린
탭을 자동으로 닫거나 합치지 않으며, 회의 원문과 작업자 채팅은 유지합니다.
이전 설치 이름 사용자는 [이전 안내](../../host-plugin/MIGRATION.md)를 먼저 확인하세요.

이번 검사는 격리된 환경의 결과입니다. 실제 앱에서 스크롤하며 탭 개수를
확인하는 검증은 아직 완료하지 못했습니다. 앱 재시작만으로 생기는 중복이나
캐시된 이전 화면까지 모두 해결됐다고 보장하지 않습니다. 앱 설치 파일·저장된
탭·캐시를 임의로 수정하거나 호스트 세션 ID를 만들어 넣지 않습니다.

## English

History cards now explicitly prefer **inline** presentation, preventing their
initial render/remount from automatically preferring a separate fullscreen tab.
Use the host's existing Expand control for a larger view. The explicit thread
menu entrypoint and fullscreen support remain available. No additional AI calls,
state reads, automatic dispatches or retries are introduced; original records,
attachments, participants and collaboration tools are unchanged.

Isolated regressions cover replay/remount without automatic expansion or work
submission, plus browser visibility/remount and explicit fullscreen/submission.
Package checks, 247 regressions, 22 browser scenarios and an isolated CLI upgrade
passed. These checks are not a native Codex scroll reproduction. Existing duplicate tabs
are not automatically closed or merged. Finish active work, close unwanted tabs,
update with the same install selector and fully quit/reopen Codex to load the new
resource settings. Cached older views and restart-only duplication remain
separate host validation limits; no host cache or session IDs are patched.
