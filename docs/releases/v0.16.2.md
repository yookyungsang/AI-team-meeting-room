# v0.16.2 · 공개 베타 · 회의실 화면 크기·복원 처리 보완

> **공개 베타 / Public beta.** 먼저 사용해 보고 의견을 보내실 수 있습니다. 실제 앱의 팀 생성, 작업·QA·중단 복구 전체 흐름과 재시작·중복 탭 동작은 추가 검증 중입니다. Native end-to-end setup, work/QA/recovery and restart/duplicate-tab validation remains incomplete. [검증 범위 / Validation scope](../../host-plugin/skills/team-room/references/host-validation.md) · [오류 제보 / GitHub Issues](https://github.com/yookyungsang/AI-team-meeting-room/issues).

앱 실행 중 종료된다는 보고를 추가 조사하고, 회의실에서 독립적으로 재현한 불필요한 크기 알림과 스타일 재적용을 줄였습니다. **앱 종료의 직접 원인은 아직 확정하지 못했으며, 이번 보완을 앱 종료 해결로 표시하지 않습니다.**

- 전체 화면에서는 앱이 정한 높이를 다시 앱에 크기 변경 요청으로 보내지 않습니다. 화면 안에 표시되는 회의실은 기존의 제한된 높이를 유지합니다.
- 같은 높이라면 스타일을 다시 쓰지 않습니다. 소수점이 달라도 실제 적용할 정수 높이가 같으면 반복 적용하지 않습니다.
- 숨겨진 패널은 호스트가 알려준 최신 크기를 기억하고, 다시 보일 때 한 번 적용합니다. 종료된 패널의 늦은 응답 차단은 유지합니다.
- 원문·입력·프로젝트 연결과 협업 절차는 유지합니다. 별도 AI·담당자 호출·자동 재전송·주기적 진단은 추가하지 않습니다.

## 확인 범위

수정 전 회귀 검사에서 전체 화면 크기 변화 40번이 크기 알림 40개를 추가하고, 같은 정수 높이의 이벤트가 반복 스타일 쓰기를 일으키는 것을 재현했습니다. 수정 후 위젯 75개를 포함한 전체 회귀 검사 237개, 패키지 검사와 격리된 실제 브라우저 레이아웃 20개 시나리오가 통과했습니다. 숨김·다시 표시·종료 후 콜백과 입력 보존도 포함합니다.

실제 앱 로그에서는 회의실 sandbox가 시작되기 전부터 화면 크기 관찰 오류가 나타났습니다. 종료 시 연결이 정리된 후의 내부 통신 오류는 종료 원인으로 단정하지 않습니다. Windows 오류 기록과 충돌 보고 목록에서 해당 실행의 직접 원인을 찾지 못했습니다. 실제 앱의 종료·재실행 비교는 미완료이며 호스트 파일이나 저장된 탭·캐시를 수정하지 않았습니다. [자세한 검증 범위](../../host-plugin/skills/team-room/references/host-validation.md).

## English

Hardens meeting layout during native startup/restore. Fullscreen viewport changes no longer emit intrinsic-size notifications back to the host. Unchanged rounded heights avoid repeated style writes. Hidden panels retain the latest host context and apply it once on visibility restoration. Existing teardown, draft preservation, project routing and no-automatic-resend guards remain unchanged; no model calls or background diagnostics are added.

All 237 regression tests (including 75 widget tests), the package check and 20 isolated real-browser scenarios passed. Focused regressions reproduced the old feedback behavior before the fix and checked the new fullscreen, unchanged-height and hidden-restore cases afterwards. The real-browser harness covers narrow and wide panes and still checks inline/fullscreen transitions. Synthetic browser results do not establish that native startup exits are fixed. Read-only local diagnostics found resize-observation errors before the meeting sandbox mounted and disconnect errors during shutdown cleanup, without establishing a direct exit cause. Native restart comparison remains unverified.
