# v0.13.0 · Team Meeting Room / 팀 회의실

The first formal GitHub release packages the current 0.13.0 plugin. Existing
installation identity and local meeting data are preserved.

- 처음 연결하는 로컬 프로젝트에서 설명 확인 후 기본 팀 구성 요청.
- 쉬운 보고와 접힌 작업 상세, 이미지·음원 첨부와 사용자 선택 미리보기.
- 파일·Editor 소유권, 중단 인계, QA 재시도 제한과 명시적 Unity 검증.
- 완료 후 관측 가능한 담당자별 사용량 표시. 누락된 값은 추정하지 않음.
- 회의실 삭제 전 진행 작업 확인, 기록 보관과 원래 구성으로 복구.
- GitHub 자동 검사: Node 22의 Windows·Linux에서 기존 테스트와 패키지 검사.

### 설치와 업데이트

Node.js 22 이상, Git, 로컬 플러그인과 MCP Apps를 지원하는 Codex가 필요합니다.
아래 명령은 터미널에서 실행합니다.

```sh
git clone --branch v0.13.0 https://github.com/yookyungsang/AI-team-meeting-room.git
cd AI-team-meeting-room
codex plugin marketplace add .
codex plugin add jyfood-room@jyfood-local
```

기존 설치는 작업을 마친 뒤 소스 폴더에서 다음 명령으로 같은 버전에 맞춥니다.
기존 파일 수정이 있으면 먼저 보존하고, checkout 충돌을 강제로 덮어쓰지 마세요.

```sh
git fetch --tags origin
git checkout v0.13.0
codex plugin add jyfood-room@jyfood-local
```

설치 후 Codex를 완전히 종료하고 다시 실행합니다. 프로젝트 채팅에서 회의실을
열고, 처음이라면 **메뉴 → 기본 팀 만들기** 설명을 확인하세요.

## English

- Project-scoped director/participant connections and menu-based roster editing.
- Explicit first-project team setup with role/model explanation before applying.
- Plain reports with folded technical detail, image/audio attachments and manual previews.
- Managed file/Editor ownership, checkpoint handoffs, QA attempt limits and explicit Unity checks.
- Observed per-participant usage after completion; unavailable data is never estimated.
- Guarded room deletion with retained history and restoration of original membership.
- GitHub checks run the existing tests and package validation on Node 22, Windows and Linux.

Use the installation commands above in a terminal, then fully restart Codex after
finishing active work. Existing installations can fetch tags, check out this
version and reinstall with the same plugin ID. Preserve local changes before
checkout. For later development, switch back to your original branch explicitly.

## Validation and scope / 검사 범위

GitHub Actions executes deterministic package checks and isolated regression
tests using synthetic data. It invokes no AI or real chats, starts no real Unity
Editor, adds no schedule and never publishes automatically. Actions uses GitHub
runner resources separately from AI token usage. The optional browser harness is
run explicitly for UI changes; actual Codex display transitions and native staff
creation remain separate host checks. The current UI labels use Korean.

플러그인 ID는 `jyfood-room@jyfood-local`, 서버 키는 `team-room`을 유지합니다.
기록은 기존 `TEAM_ROOM_HOME` 또는 사용자 홈의 Codex 회의실 데이터 폴더에 남습니다.
이 릴리스는 실제 사용자 기록을 포함하지 않습니다. GitHub의 **Source code**
다운로드에는 설치에 필요한 저장소 구조가 포함되며, 자동 설치 프로그램은 아닙니다.
