# v0.16.0 · 백업 불러오기와 일본어·중국어 설명서

## 백업 불러오기

**메뉴 → 백업 불러오기**에서 이 플러그인으로 만든 ZIP을 선택하고, 이름·담당자·발언·첨부 수를 확인한 뒤 **확인한 회의실 복구**를 누릅니다. 파일 선택은 16 MiB까지, 직접 입력한 절대 로컬 파일 경로는 128 MiB까지 지원합니다. 파일은 로컬 플러그인에만 전달하며 AI·외부 업로드·작업 재실행은 없습니다.

- 원래 프로젝트와 기존 총괄·담당자 소속을 확인해 **없어진 회의실만** 복구합니다. 기존 기록을 덮어쓰거나 합치지 않고 다른 프로젝트로 옮기지 않습니다. 삭제해서 보관한 회의실은 기존 메뉴 복구를 사용합니다.
- 진행 중인 작업이 포함된 백업, 손상된 ZIP·첨부, 프로젝트나 담당자 연결을 확인할 수 없는 경우는 복구를 거절합니다. 해당 ZIP의 `index.html`은 오프라인 열람용으로 사용할 수 있습니다.
- 원문·작업 상세·이미지·음원·담당자 연결·구성원 버전과 변경 이력을 유지합니다. 복구 후 새 요청은 일시정지되므로 기록 확인 후 직접 재개합니다.
- 작업 폴더 승인, 프로젝트 소스 파일, QA/작업 제어 원장, 사용량 자료, 실제 Codex 채팅은 가져오지 않습니다. 현재 로컬의 소유권·시도·사용량 기록을 덮어쓰지 않으며, 복구 뒤 작업 폴더는 총괄이 다시 확인해야 합니다. 없는 사용량은 추정하지 않습니다.
- 중단된 복구는 **이전에 준비한 복구 확인 → 이어서 확인**에서 원래 기록으로 확인합니다. 같은 요청의 명시적 재확인만 허용하고, 새로 생긴 기록은 보존합니다. 자동 재시도·주기 AI 호출은 추가하지 않았습니다.

## 설치·업데이트

```sh
git clone https://github.com/yookyungsang/AI-team-meeting-room.git
cd AI-team-meeting-room
codex plugin marketplace add .
codex plugin add jyfood-room@jyfood-local
```

기존 설치는 원본 저장소에서 `git pull --ff-only` 후 `codex plugin add jyfood-room@jyfood-local`로 갱신합니다. 진행 중인 작업을 마친 뒤 앱을 다시 여세요. 플러그인 ID `jyfood-room@jyfood-local`와 MCP 서버 `team-room`, 외부 런타임 데이터 위치는 유지합니다.

## English

Adds explicit ZIP recovery for a missing, finished room in its verified original local project. Upload up to 16 MiB in bounded local chunks, or enter a local ZIP path up to 128 MiB. Preview and a separate confirmation precede paused recovery. Existing history is never overwritten or merged; unfinished work, foreign scope, missing participants, damaged media and unsafe archives block restoration. Saved import journals reconcile interruptions only on explicit user action. No native chats, workspace authority, work-control/QA ledgers, usage sources, model runtime or automatic retries are imported or added. Existing local controls and measurements remain untouched; recovered rooms require fresh workspace confirmation before managed file/Editor work.

New Japanese, Simplified Chinese and Traditional Chinese installation/user manuals are packaged and linked prominently from GitHub. UI and reports are not automatically translated, and ordinary work retains its normal usage. Instructions are read only when needed.

Installed-host read-only room opening/project recognition succeeded. Local tab-instance code was inspected, but native restart duplication and complete team-creation/messaging/approval flows remain unverified. No host code or state cache was patched. Synthetic browser/store checks are reported separately from actual Codex integration.

## Validation

`npm run check:package` and all 230 regression tests passed. The real ZIP-upload/recovery browser harness passed 10 cases covering five languages at 420px and 1280px, alongside the existing layout/lifecycle/language checks. No live agents were invoked.

Isolated regression tests cover archive integrity, traversal/duplicate/encrypted/compressed entry rejection, original-route verification, no overwrite, interrupted commits, exact retries, native scope changes, workspace reauthorization, source preservation and late UI callbacks. The browser harness uses real ZIP uploads and real plugin storage at 420px/1280px in all five languages, verifying preview before restore, paused state, original text/media and no duplicate recovery. Actual native-host transitions remain outside that fixture coverage.
