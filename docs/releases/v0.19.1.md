# v0.19.1 · 공개 베타 · 팀 제어를 메뉴 위쪽으로

회의실 메뉴를 열면 **팀과 회의 제어**가 먼저 표시됩니다. 구성원 편집과 새 요청
일시정지를 백업·입력 안내보다 위에서 찾을 수 있습니다. 아직 팀을 연결하지 않은
프로젝트에서는 기본 팀 만들기를 먼저 안내합니다. 화면 언어 등 보조 설정은
그 아래에 배치했습니다.

메뉴를 아래까지 스크롤했어도 닫았다 다시 열면 맨 위로 돌아갑니다. 같은 구성
요소를 문서 순서대로 이동하여 키보드 탐색과 다국어 메뉴에도 동일하게 적용합니다.
기존 작업·전송·승인·회의 기록의 동작에는 변경이 없으며 AI 호출을 추가하지 않습니다.

큰 화면과 작은 화면의 브라우저 검사에서 팀 제어·구성원 편집의 첫 화면 표시,
메뉴 재열기 시 맨 위 복귀와 초안 보존을 확인했습니다. 화면 동작 검사 87개와
격리 브라우저 검사 28개를 통과했습니다. 격리 브라우저 검사는 실제
Codex의 새 설치 화면 확인을 대신하지 않습니다. [검증 범위](../host-validation.md).

소스 업데이트 후 아래 명령으로 갱신하고 Codex가 포함된 앱을 완전히 다시 실행해
새 버전을 불러오세요. 이미 열린 구버전 회의실 탭은 직접 정리해 주세요.

```sh
git pull
codex plugin marketplace add .
codex plugin add team-room@team-room-local
```

## English

The menu now places team controls first: member editing and pause/resume for new
requests appear before backup and delivery help. Unconnected projects see basic
team setup first. Language and other secondary settings follow. Reopening the
menu returns to the top, preserving the chat draft. DOM order also preserves
keyboard and localized reading order. No AI, routing or work-control behavior is
added. Browser checks cover wide/narrow placement and reopen behavior; native
updated-display verification remains separate. Reinstall through the same plugin
selector and fully restart the app. This release remains a public beta.
