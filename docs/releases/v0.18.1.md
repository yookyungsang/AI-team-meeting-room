# v0.18.1 · 공개 베타 · 한 번만 자동으로 회의실 탭 열기

새 `room_open` 요청은 로컬의 일회용 열기 기록을 먼저 저장한 뒤 상단 탭 전환을
한 번 요청합니다. 사용한 카드의 재표시·상태 갱신·숨김 복원으로 재요청하지 않습니다.
기본 리소스는 inline으로 유지해 기록 확인 전에 예전 카드가 자동 확장되지 않게 합니다.

같은 프로젝트의 열기 기록이 남아 있으면 새 탭 요청을 보류하고, 카드에서 기존
상단 탭을 먼저 확인하도록 안내합니다. 탭이 실제로 없을 때만 **기존 탭 없음 ·
다시 열기**를 눌러 한 번 복구할 수 있습니다. 이 안내는 채팅 입력·전송이나
총괄·담당자의 작업을 막지 않습니다. 다섯 화면 언어를 지원합니다.

명시적인 화면 종료/inline 전환만 자기 열기 기록을 해제합니다. 앱 강제 종료나
응답 유실·시간 경과만으로는 해제하지 않습니다. 오래된 확인이나 종료 응답이
새 기록을 덮어쓰지 않습니다. 표시 기록은 원문·라우팅·백업과 분리하며 별도 AI,
heartbeat, 정기 표시 조회나 자동 재전송을 추가하지 않습니다.

**완전한 native 탭 중복 제거 기능은 아닙니다.** 기존 탭 조회·선택·통합·닫기 API가
없어 수동 펼치기, 호스트 메뉴, 구버전 탭이나 사용자가 잘못 확인한 경우까지
제어할 수 없습니다. 업그레이드 뒤 처음 사용하기 전 구버전 탭은 직접 정리하세요.
실제 Codex 전환·재시작 검증과 격리된 검사를 구분합니다.

설계·사용법: [일회용 탭 열기와 한계](../../host-plugin/skills/team-room/references/room-opening.md).

## English

Fresh openings durably consume a one-use UI ticket before requesting fullscreen.
Historical replays do not reopen it. Existing/uncertain occupancy requires a
nonmodal human no-old-tab check, with fenced one-shot recovery. Original records,
routing, director input and work remain independent. No AI, heartbeat or periodic
display polling is added. This is a conservative guard, not native tab discovery
or a guarantee covering manual host controls, old versions and crash restoration.
