# v0.15.0 · 일본어와 중국어 간체·번체

**메뉴 → 화면 언어 / Language**에서 한국어, English, 日本語, 简体中文(간체), 繁體中文(번체)을 고를 수 있습니다.

- 자동은 브라우저의 한국어·일본어·중국어 설정을 따릅니다. 중국어는 Hans/Hant 표기가 있으면 이를 우선하고, 없으면 대만·홍콩·마카오 설정은 번체, 그 외 중국어 설정은 간체를 사용합니다. 다른 언어는 영어로 표시합니다. 위치 조회는 하지 않습니다.
- 메뉴, 안내, 작업 상태, 연결 점검 설명과 새 팀 만들기 요청문에 미리 작성한 번역을 사용합니다. 선택은 로컬 저장이 가능한 환경에서 유지됩니다.
- 언어를 바꿔도 기존 발언·작업 상세·첨부 설명·작성 중인 글·모델은 바꾸지 않습니다. 이미 준비한 팀 설정은 원래 언어와 연결·시도 기록을 유지합니다.
- 별도 번역 AI·언어 판정 서비스·정기 호출은 없습니다. 실제 작업과 직접 전송한 팀 생성 요청에는 일반 사용량이 있습니다. 전체 사용·설치 설명서는 한국어와 영어로 제공합니다.

## 설치·업데이트

처음 설치할 때:

```sh
git clone https://github.com/yookyungsang/AI-team-meeting-room.git
cd AI-team-meeting-room
codex plugin marketplace add .
codex plugin add jyfood-room@jyfood-local
```

기존 설치는 원본 저장소에서 `git pull --ff-only` 후 `codex plugin add jyfood-room@jyfood-local`로 갱신합니다. 진행 중인 작업을 마친 뒤 Codex를 다시 열어 새 화면을 사용하세요. 기존 플러그인 ID `jyfood-room@jyfood-local`와 MCP 서버 `team-room`, 외부 런타임 기록은 유지됩니다.

## English

Adds Japanese, Simplified Chinese and Traditional Chinese to the existing Korean/English UI. **Menu → Language** offers Auto and five explicit choices. Chinese script tags take precedence; TW/HK/MO locales otherwise use Traditional Chinese, and other Chinese locales use Simplified Chinese. Auto uses English for other unsupported browser languages. No location lookup is performed.

Packaged text covers menus, instructions, status labels, connection-check explanations and new team-setup drafts. Existing setup journals retain their original language, identity, models and attempts. Original posts, work details, media captions and typed drafts are never automatically translated. No translator AI, new background work or periodic calls are added. Complete manuals remain Korean/English.

## 검증 범위 / Validation scope

`npm run check:package` passed; all 215 regression tests passed. The isolated browser harness passed at both 420px and 1280px for all three added languages, alongside the existing UI checks.

Isolated tests cover dictionary completeness, browser-language and script selection, saved preferences, repeated five-language switches, exact draft/post/media preservation and localized setup continuation with unchanged model/routing guards. The browser harness checks 420px and 1280px layouts, localized diagnostics, preference reload and no horizontal menu overflow. These checks use synthetic records and no live agents. Actual Codex display-mode transitions and native chat creation remain separate, unverified host integration checks.
