# v0.18.0 · 공개 베타 · 작업을 막지 않는 비밀값 경고와 공유용 사본

회의실 메시지와 작성 중인 텍스트에서 일부 API 키·접근 토큰·개인키·명시적인
인증정보 패턴을 로컬 코드로 확인합니다. 의심값이 있으면 화면에만 경고하며,
총괄·담당자의 게시·배정·완료 처리를 중단하거나 재승인을 요구하지 않습니다.
발견한 값은 경고나 검사 결과에 다시 담지 않습니다. 원문과 첨부는 유지합니다.

## 공유하기

메뉴의 **공유용 ZIP 만들기**에서 **공유 사본에서 의심되는 비밀값 가리기**를
선택합니다. 기본은 가림이며, 사용자가 해제하면 해당 사본에 원문 텍스트를
유지합니다. 회의 원문·작업 상세·표시 이름·첨부 설명의 감지된 부분만 사본에서
`[REDACTED]`로 바꿉니다. ZIP을 만들거나 다운로드하는 동작은 직접 눌렀을 때만
실행하며, 외부 업로드는 하지 않습니다.

공유용 사본은 열람용 문서와 원래 첨부파일을 포함합니다. 복구용 연결 정보인
`project.json`과 `room.json`은 넣지 않으며 회의실 복구에 사용할 수 없습니다.
**ZIP으로 백업**은 기존과 같은 개인 복구용 원본이므로 비밀값도 그대로 포함할
수 있습니다. 원본 백업과 공유용 사본을 구분해 사용하세요.

같은 공유 ID와 가림 선택을 다시 저장하면 기존 파일을 반환합니다. 선택을
바꾸면 새 ID를 사용해 이전 사본을 덮어쓰지 않습니다. 메뉴 닫기·프로젝트 변경·
화면 숨김·종료 뒤 늦게 도착한 결과가 화면을 다시 열거나 전달을 시작하지 않게 합니다.

## 범위와 사용량

- 감지는 알려진 텍스트 패턴을 이용하는 보조 경고입니다. 예시를 잘못 감지하거나
  실제 비밀값을 놓칠 수 있습니다. 공유 전 사본을 직접 확인하세요.
- 이미지·음원 내부와 숨은 메타정보, 다른 AI 도구로 직접 전달한 내용, 작업 폴더의
  파일은 검사하지 않습니다. 이미 모델에 전달된 값을 되돌리는 기능이 아닙니다.
- 일반 파일 작업·이미지·음원 첨부에는 새 접근 제한을 추가하지 않습니다.
  이름 등 다른 개인정보를 자동으로 익명화하는 기능도 아닙니다.
- 별도 AI 호출·분류기·번역·정기 조회·자동 재전송은 추가하지 않습니다. 검사와
  가림은 로컬에서 처리하고, 경고는 모델 응답에 추가하지 않습니다. 도구 설명과
  지침의 짧은 설명에는 일반 문맥 사용량이 있습니다.

## 업데이트

기존 소스 폴더에서 `git pull` 후 `codex plugin add team-room@team-room-local`을
실행합니다. 진행 중인 작업을 마친 뒤 Codex를 완전히 종료했다가 다시 실행하세요.
설치 ID·MCP 이름·기존 회의 기록과 담당자 연결은 유지합니다. 이전 이름 설치는
[이전 안내](../../host-plugin/MIGRATION.md)를 확인하세요.

검사는 가상 기록·담당자·합성된 테스트 값과 격리된 브라우저로 수행합니다.
패키지 검사(문서 링크 339개), 회귀 검사 259개와 브라우저 시나리오 24개가
통과했습니다. 두 화면 크기에서 가림/원문 공유 ZIP의 실제 다운로드와 원문·
입력 보존을 확인했습니다. 별도 설치 환경에서 v0.17.2 → v0.18.0 업데이트,
설치 파일 65개의 원본 일치와 MCP 시작을 검사했습니다. Windows의 임시 파일/
junction 및 테스트용 로컬 페이지 권한이 필요한 검사는 같은 가상 데이터만
샌드박스 밖에서 실행했습니다.

실제 Codex 화면의 전체 작업·스크롤·재시작 검증 범위는 [기존 안내](../../host-plugin/skills/team-room/references/host-validation.md)를
따릅니다. [설계와 보호 범위](../../host-plugin/skills/team-room/references/secret-sharing.md)도 함께 확인하세요.

## English

Selected secret patterns in meeting/draft text now produce **UI-only, non-blocking
warnings**. Originals remain exact; posting, delegation and director completion
continue without extra approval, model messages or AI calls. Warning summaries
contain no matched values.

Menu → Create sharing ZIP offers masking (default) or original text for that
copy. Sharing copies contain reading documents and unchanged media, omit connection/recovery
JSON, and cannot restore a room. Exact private backups remain unchanged and
can contain secrets. Export IDs bind the format/choice and safely reuse the same
archive on a storage retry; changing the choice creates a new copy.

Pattern matching can miss secrets or flag examples. Images, audio, embedded media
metadata, other AI tools and workspace files are outside this text-only feature.
Review copies before sharing. No new file restrictions, background AI, polling,
resends or external uploads are introduced. Brief documentation/schema additions
still have normal context overhead. Package checks, 259 regressions, 24 isolated
browser scenarios and a separate CLI upgrade/startup check passed. Update with the same plugin selector and
fully restart Codex after finishing active work; native-app lifecycle verification
remains separate from isolated tests.
