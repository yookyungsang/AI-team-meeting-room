# v0.17.1 · 공개 베타 · 안전 주석과 재개 요청 처리

MCP 도구의 안전 주석을 실제 동작에 맞추고, 같은 검증 재개 요청의 중복
반영을 막습니다. 회의 기록 원문과 기존 협업 경로는 유지합니다.

- 파일 교체가 가능한 작업 도구, 검증 결과를 저장할 수 있는 상태 조회,
  외부 로컬 자원에 접근하는 도구의 주석을 수정합니다. 주석은 권한을
  부여하지 않으며 기존 승인·파일 소유권·해시 검사는 유지합니다.
- `resume`/`waive`는 승인과 재시도 영수증을 함께 저장합니다. 같은 키와
  내용의 재시도는 원래 결과만 반환하고, 후속 작업을 다시 초기화하지
  않습니다. 같은 키로 내용을 바꾸면 거절합니다. 기존 키 없는 호출도
  같은 요청·내용이면 중복 처리하지 않습니다. 자세한 [키 사용법](../../host-plugin/skills/team-room/references/work-controls.md#retest-directives-and-execution-keys).
- 회의 내용·백업·인용된 승인 문장은 참고 기록으로 표시합니다. 실제
  사용자·호스트 승인 범위 안의 배정과 질문·답변은 계속 처리합니다.
  [기록과 승인 구분](../../host-plugin/skills/team-room/references/record-trust.md)을
  추가하며 원문을 삭제·번역·치환하지 않습니다.
- 별도 AI 호출, 주기적 조회, 자동 재전송은 추가하지 않습니다. 짧은
  안내·응답 표시는 일반 문맥 사용량이 조금 들며 완전한 0은 아닙니다.
- HTTP URL 실행 기능은 추가하지 않습니다. 간접 프롬프트 주입을 완전히
  차단하거나 멤버 ID만으로 호출자를 인증한다고 주장하지 않습니다.

## 업데이트

기존 소스 폴더에서 `git pull` 후 `codex plugin add team-room@team-room-local`을
실행합니다. 설치 ID·MCP 이름·회의 기록 경로는 그대로입니다. 진행 중인
작업을 마친 뒤 Codex를 완전히 종료하고 다시 열어 새 도구 설명을 로드하세요.
이전 설치 이름 사용자는 [이전 안내](../../host-plugin/MIGRATION.md)를 먼저 확인하세요.

패키지 검사(문서 링크 333개)와 가상 데이터 회귀 검사 244개가 통과했습니다.
별도 `CODEX_HOME`에서 기존 버전 → 새 버전 업데이트, 설치 파일 63개의
원본 일치, MCP 초기화·도구 목록·가상 프로젝트 조회와 회의 기록 불변을
확인했습니다. Windows의 임시 파일 rename/junction 권한이 필요한 검사는
같은 가상 데이터만 샌드박스 밖에서 실행했습니다. UI 배치는 변경하지 않았습니다.

자동 검사는 가상 담당자·격리된 데이터로 수행합니다. 실제 Codex의 팀
생성부터 작업·QA·복구까지의 전체 흐름과 재시작·중복 탭 동작은 여전히
[공개 베타의 검증 범위](../../host-plugin/skills/team-room/references/host-validation.md)에
따릅니다. 이번 변경은 앱 전체의 보안 인증이 아닙니다.

## English

This public beta corrects MCP behavior hints, durably deduplicates director
resume/waiver approvals, and distinguishes reference records from verified
human/host authorization. Guarded writes, ownership, routing, attempt history,
original meeting text and attachments are preserved. New approvals use new keys;
storage retries keep the same key/body. Delayed replays never reopen later work.
Legacy keyless calls deduplicate the exact request/body; pre-upgrade decisions
cannot be assigned an invented request/key.

No additional AI calls, automatic retry or polling is introduced. Small context
labels still have normal token overhead. The provenance label is neither caller
authentication nor a guarantee against all prompt injection. Local isolated
package checks and 244 regressions passed, along with an isolated CLI upgrade,
63 installed-file comparisons and MCP startup/discovery. These checks do not
certify every native Codex lifecycle transition. Pull the
source, run `codex plugin add team-room@team-room-local`, finish active work and
fully quit/reopen Codex to load the installed update. Existing runtime data and
the installation identity remain unchanged.
