# Walkthrough media credits / 사용 영상 출처

The `team-room-walkthrough.*` videos/posters and `team-room-guide.ko.png` are
documentation media approved for publication by the project owner on
2026-10-31. They depict the actual Team Room UI and an existing project's
conversation and game image. Person names are masked. Raw captures, chat
identifiers, routing registries, local source paths and private editing metadata
are not included.

Background music: **ElevenMusic — created in collaboration with ElevenLabs**,
using ElevenLabs Music v2. One original 60-second instrumental was generated
for this tutorial and reused in both language versions. It is embedded at low
volume with fade-in/out. No standalone source MP3 is published here.
